## 📌 Project Overview

The **EPL SQL Data Analysis** project is a structured data analytics project developed using **PostgreSQL**. It analyzes English Premier League player-level and match-level statistics to explore performance trends, scoring efficiency, team contributions, disciplinary records, match attendance, and other key football metrics.

The project uses SQL to transform raw statistical data into meaningful analytical outputs through a progression of increasingly complex queries. The analysis begins with fundamental data exploration and aggregation before advancing to conditional analysis, subqueries, Common Table Expressions (CTEs), Window Functions, and ranking techniques.

Beyond football analytics, the project demonstrates practical SQL competencies applicable to broader **data analytics, business intelligence, and database analysis** environments.

---

## 🎯 Project Objectives

The primary objectives of this project are to:

- Explore and analyze a structured sports dataset using SQL.
- Evaluate individual player performance across Premier League matches.
- Compare team-level performance using key statistical indicators.
- Identify leading goal scorers and high-performing players.
- Analyze goals, assists, shots, and goal conversion efficiency.
- Evaluate player participation through appearances and minutes played.
- Examine disciplinary performance using cards and fouls.
- Analyze match attendance and match-week statistics.
- Apply advanced SQL techniques to solve analytical problems.
- Demonstrate practical PostgreSQL and data analysis skills through a portfolio-ready project.
